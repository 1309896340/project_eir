变异检出 vs 注入真值

演示的独有优势:模拟时已知全部"真值"变异,可直观看到 depth / 质量 / 频率过滤的灵敏度与特异性(真实流程无真值,靠验证集评估)。

Per-cycle 测序质量 FastQC

Illumina 特征:read 前端质量高、末端线性衰减; 四分位带反映波动,低质量 reads 拉宽分布。纵轴为 Phred Q。

GC 含量分布 FastQC

每条 read 的 GC 百分比直方图;合成基因组目标 GC ≈ 38%。

基因组覆盖深度 samtools · mpileup

变异位点 ivar variants

POS类型REFALT DPAFQUALFILTER

过滤规则与 ivar 默认一致:DP<10 → LOW_DEPTH, QUAL<20 → LOW_QUAL,AF<0.75 → LOW_FREQ。POS 为 1-based。

共有序列 ivar consensus

多数碱基占比 ≥ 0.75 才调用,否则写 N; 高频缺失位从共识移除、高频插入按众数串补回,故长度可不同于参考。

模拟口径:测序错误概率与 Phred 质量自洽(p=10−Q/10); 比对为理想化定位(真实流程用 bowtie2);变异/共识阈值复刻 ivar 默认。
