# ViralRecon 演示台 · 使用手册

## 这是什么

参考 [nf-core/viralrecon](https://github.com/nf-core/viralrecon) 的流程概念打造的
**自包含教学演示**:在浏览器里体验 病毒重测序分析 的完整链路——

```text
模拟 FASTQ → 质控统计 → 比对+pileup → 变异检测(SNP/Indel) → 共有序列(consensus)
```

- 数据为**合成模拟**(冠状病毒样 GC≈38% 的随机基因组 + 种子驱动的变异与 reads),
  不涉及任何真实病原体序列;与官方 viralrecon 项目无隶属关系。
- 计算为纯 Python 简化实现,标准参数下亚秒级出结果,零外部依赖、离线可用。
- 每一步的口径尽量对齐真实工具(见下表),便于建立"参数 → 结果形态"的直觉。

| 演示步骤 | 简化实现 | 真实工具(viralrecon) |
|---|---|---|
| reads 质量模型 | Q 前高后低 + 低质量 reads 子集 | Illumina 原始数据 |
| per-cycle 质量/GC | 流式统计 + 分位数 | FastQC / MultiQC |
| 比对 | 理想化定位(坐标已知) | bowtie2 / minimap2 |
| 覆盖深度 | mpileup 口径计数 | samtools mpileup |
| 变异检测 + 过滤 | DP/QUAL/AF 三重阈值 | ivar variants |
| 共有序列 | 多数碱基 + min_frac | ivar consensus |

## 启动

```bash
uv run python -m viralrecon.app    # 或:uv run viralrecon-app
```

浏览器自动打开 http://127.0.0.1:7862 。VS Code 里也可直接 F5
(launch.json 已配置 "ViralRecon 演示台 (FastAPI :7862)")。

## 界面操作

1. **选预设档**:快速预览(2kb·60x) / 标准教学(5kb·100x) / 冠状病毒规模(30kb·120x);
2. **(可选)展开高级参数**:覆盖深度、read 长度、注入变异数、错误率缩放、
   低质量 reads 比例、覆盖模式(amplicon 扩增子波浪 / uniform 均匀)等,留空用预设;
3. **(可选)设随机种子**:同种子结果完全可复现,适合课堂演示对照;
4. 点 **▶ 生成分析报告**,约 0.1–3 秒返回。

## 报告解读

- **Summary 卡片**:reads 数、平均深度、覆盖广度(≥1x)、≥10x 比例、PASS 变异数、
  平均 GC、耗时。基因组两端深度自然衰减(read 无法完整覆盖,与真实比对一致)。
- **真值对照**:演示独有——注入了多少"真值"变异、检出多少(TP)、漏检多少(FN)、
  假阳多少(FP)。真实流程无真值,这里用来直观理解过滤阈值的灵敏度/特异性。
- **Per-cycle 质量图**:绿色区(Q≥28)为高质量;四分位带越宽说明波动越大;
  低质量 reads 比例高时整条带下移。虚线为 Q20 参考线。
- **GC 分布**:应集中在 ~38% 附近的单峰。
- **覆盖深度图**:amplicon 模式呈 ~1200bp 周期的波浪(扩增子效率差异),
  这是真实 amplicon 测序报告最典型的形态;波谷处易触发 LOW_DEPTH 过滤。
- **变异表**:POS 为 1-based;AF = 支持碱基比例;过滤规则与 ivar 默认一致
  (DP<10 → LOW_DEPTH,QUAL<20 → LOW_QUAL,AF<0.75 → LOW_FREQ)。
  可切换 全部/仅 PASS/仅被过滤,并导出 TSV。
- **共有序列**:多数碱基占比 ≥0.75 才调用,不足写 N;高频缺失移除、高频插入补回,
  故长度可不同于参考。可导出 FASTA。

## 推荐演示场景

1. **过滤阈值的直觉**:把 覆盖深度 降到 15–20x,观察波谷/末端位点转为
   LOW_DEPTH、FN 上升;再把 错误率缩放 拉到 10–20,看 LOW_QUAL 假阳出现。
2. **覆盖模式对比**:amplicon vs uniform——波浪 vs 平坦,及对变异检出的影响。
3. **可复现性**:同种子跑两次结果完全一致;换种子观察泊松随机性。
4. **冠状病毒规模**:30kb 档约 2–3 秒,观察 N 比例与深度图形态。

## 常见问题

- **想跑真实数据/真实流程**:见同目录《环境安装交接.md》
  (WSL2 + Docker + Nextflow,一行命令跑官方 test profile,产出真实 MultiQC 报告)。
- **运行报"计算预算超限"**:基因组长度×覆盖度超过 450 万碱币上限,
  调小 genome_len 或 coverage。
- **FP 不为零**:错误率缩放调得过高时,测序错误在同一位点聚集成"高频"假阳——
  这正是真实流程需要 QUAL/DP 过滤的原因。
- **端口冲突**:7862 被占用时改 `app.py` 中 `main()` 的端口常量。
