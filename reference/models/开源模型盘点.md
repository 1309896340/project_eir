# 开源模型盘点(开放权重、可直接推理)

> 盘点日期:2026-09-24。目的:为密码子优化分析与后续模型实现寻找**已训练好、权重公开可下载、可直接部署推理**的开源模型,并与本项目数据集(`data/` 中的 CoCoPUTs 统计表、GENCODE 序列库)和 `mRNA模型设计.md` 的模块设计对应。
>
> 说明:链接均经检索核实;各模型许可证不一,商用前需逐个到模型页确认 License。标注 ★ 的为该任务域首选。

## 一、密码子优化 / CDS 设计(核心需求,权重最全)

对应设计文档的**条件生成模型(CDS 同义序列设计)**模块;CoCoPUTs 统计表可直接用于校验这些模型输出的人类密码子偏好。

| 模型 | 权重位置 | 论文 | 说明 |
|---|---|---|---|
| ★ CodonTransformer | GitHub: `adibvafa/CodonTransformer`;HF: `adibvafa/CodonTransformer`(2M+ 下载);数据集 `adibvafa/CodonTransformer` | Fallahpour et al., Nature, 2025 | 164 物种、100 万+ DNA-蛋白对训练的 BigBird 模型;`pip install codontransformer` 即用;支持按宿主(含 human)做密码子优化与序列物种归属预测;官方 Colab 教程。与设计文档"条件生成 + 同义约束输出层"思路最接近 |
| codonGPT | HF: `naniltx/codonGPT` | Rajbanshi et al., Bioinformatics, 2025 | GPT-2 架构,直接在蛋白编码 DNA/mRNA 序列上从头训练的生成式密码子语言模型;论文展示可在不动权重的情况下叠加强化学习做蛋白级优化 |
| CodonBERT (Sanofi) | GitHub: `Sanofi-Public/CodonBERT`(权重获取方式以 repo README 为准) | Li et al., 2024(bioRxiv 2023-11 预印本) | 密码子级 BERT,1000 万 mRNA 序列预训练,面向 mRNA 设计/表征任务(表达、免疫原性等 benchmark);开放程度弱于前两者,建议作对比参考 |
| LinearDesign | GitHub: `LinearDesignSoftware/LinearDesign`(微软/百度 PaddleHelix) | Zhang et al., Nature, 2023 | 非神经网络但必列:动态规划在 CAI 与 MFE 之间全局寻优,SARS-CoV-2 spike 11 分钟出最优设计;无权重需求,编译即用,是所有学习型密码子优化模型的标配 baseline |
| DeepCodon | 论文 Code availability 节给出 GitHub(Protein Science 官网可查),另有在线 web server | Han et al., Protein Science, 2025 | 稀有密码子簇感知的深度学习密码子优化(保留翻译节奏相关的 rare codon clusters),面向大肠杆菌异源表达验证;权重开放程度需到 repo 确认 |

附带(较弱的备选):ICOR(GitHub: `Lattice-Automation/icor-codon-optimization`,RNN、MATLAB 训练)。

## 二、5'UTR 翻译效率 / 核糖体载量预测

对应设计文档的**多任务预测器**模块与 Optimus 5-Prime 数据路线(`reference/datasources/Optimus 5-Prime数据源.md`)。

| 模型 | 权重位置 | 论文 | 说明 |
|---|---|---|---|
| ★ UTR-LM | GitHub: `a96123155/UTR-LM`;HF 非官方实现: `multimolecule/utrlm-te_el` | Chu et al., Nature Machine Intelligence, 2024(6:449–460) | 内源多物种 5'UTR + 随机 5'UTR 半监督预训练(辅助任务:k-mer 掩码、二级结构、MFE);翻译效率(TE)、核糖体载量(RL)预测优于 Optimus 与 RNA-FM,当前该任务 SOTA |
| Optimus 5-Prime | GitHub: `pjsample/human_5utr_modeling`(repo 含训练好权重) | Sample et al., Nature Biotechnology, 2019 | 28 万条随机 50nt 5'UTR 的 MPRA(polysome profiling)训练的一维 CNN,预测 mean ribosome load,测试集解释 93% 方差;经典基线,即本项目 Optimus 数据路线的配套模型 |
| Framepool | GitHub: `karollus/framepool` | Karollus, Avsec & Gagneur, PLoS Comput Biol, 2021(17(5):e1008989) | frame pooling 操作使任意长度 5'UTR 的 MRL 预测成为可能,补齐 Optimus 仅 50nt 的限制;权重在 repo |

附带(生成式 5'UTR 设计):UTRGAN(GitHub: `ciceklab/UTRGAN`,以 Framepool 为打分器做 5'UTR 生成)、Smart5UTR(GitHub: `deepomicslab/Smart5UTR`,多任务自编码器)。

## 六、缺口(与 `mRNA模型设计.md` 第四部分结论一致)

- **免疫原性、IVT 可制造性**:截至盘点日无开放权重的预训练模型,维持"规则特征近似 + 自建实验数据"路线。
- **mRNA 半衰期(half-life)**:公开预训练模型基本空白;退化方案是用 RibonanzaNet / OpenVaccine 系模型输出结构/降解代理指标。
- GTEx/HPA 天然表达量不能当设计标签的约束不变(见 AGENTS.md 关键领域规则)。

## 七、建议落地顺序

1. **基线闭环**:`pip install codontransformer` + cubar。用去重后的人类 CDS(`data/o537-Human_CDS.primary_genomic_deduplicated.tsv`)校验 CAI/密码子对统计;对同一蛋白生成宿主=human 的优化序列,与 LinearDesign 输出对比,形成"密码子优化分析"基线。
2. **打分器接入**:UTR-LM / Framepool 做 5'UTR 翻译效率打分;RibonanzaNet 输出配对概率,验证结构感知模块的 attention bias 设计。
3. **自研起步**:蛋白侧 ESM-2、核酸侧 Evo-2 7B 或 Nucleotide Transformer 作微调起点,按设计文档训练流程(自监督预训练 → 监督微调 → 生成训练 → 主动学习)推进。

## 八、部署注意事项

- HuggingFace 下载:国内网络可设 `HF_ENDPOINT=https://hf-mirror.com` 后用 `hf download`;GitHub release / repo 内置权重用 git clone 即可。
- 运行环境统一为 PyTorch + transformers;CodonTransformer 另有独立 pip 包;cubar 为 R 包。
- 部分模型(HF 上的 `multimolecule/*` 系列)为社区非官方移植,结果复现请以官方 repo 权重为准。
- 各模型许可证需逐一确认后再决定商用范围;mRNA 药物设计属商业敏感场景,建议在选型评审时记录每个模型的 License 结论。
