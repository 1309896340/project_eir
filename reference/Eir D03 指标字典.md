# mRNA 设计评价指标字典与验收标准

以下指标用于评估 **Patient-mRNA Designer** 的生成模型、预测模型、约束系统和最终候选。评价分两层：

- **离线/计算指标**：模型预测、序列性质、约束满足。
- **实验/湿实验指标**：表达、半衰期、TE、免疫、可制造性。

所有实验标签必须保留 metadata：细胞类型、物种、修饰核苷酸、递送方式、剂量、时间点、批次、归一化方法。不同实验的绝对值不可直接混合，优先使用相对对照、z-score、rank 或 pairwise 排序。

## 1.1 综合评分函数

用于多目标排序和 Pareto 候选输出：

\[
\text{Score} = w_1 \cdot \text{Expression} + w_2 \cdot \text{Stability} + w_3 \cdot \text{TE} - w_4 \cdot \text{Immunogenicity} - w_5 \cdot \text{ManufacturingPenalty} - w_6 \cdot \text{ConstraintViolation}
\]

其中：

- `Expression`：预测或实验表达；
- `Stability`：预测或实验半衰期；
- `TE`：翻译效率；
- `Immunogenicity`：免疫激活风险；
- `ManufacturingPenalty`：可制造性惩罚；
- `ConstraintViolation`：约束违反惩罚。

权重按场景配置：

| 场景 | w1 表达 | w2 稳定 | w3 TE | w4 免疫 | w5 制造 | w6 约束 |
|---|---|---|---|---|---|---|
| 蛋白替代 | 0.35 | 0.30 | 0.15 | 0.10 | 0.05 | 0.05 |
| 肿瘤新抗原疫苗 | 0.30 | 0.20 | 0.20 | 0.20 | 0.05 | 0.05 |
| 体外科研 | 0.30 | 0.20 | 0.25 | 0.05 | 0.15 | 0.05 |
| 细胞治疗 | 0.25 | 0.20 | 0.20 | 0.15 | 0.10 | 0.10 |

# 二、约束违反率细分

| 约束类型 | 具体项 | 目标 | 处理方式 |
|---|---|---|---|
| 硬约束 | 翻译后蛋白不一致 | 0% | 直接淘汰 |
| 硬约束 | 内部终止密码子 | 0% | 直接淘汰 |
| 硬约束 | 移码 | 0% | 直接淘汰 |
| 硬约束 | GC 超出 40%–60% | 0% | 直接淘汰或重新生成 |
| 硬约束 | 同聚物 > 4 | 0% | 直接淘汰 |
| 硬约束 | 禁用 motif | 0% | 直接淘汰 |
| 硬约束 | 禁用酶切位点 | 0% | 直接淘汰 |
| 硬约束 | 安全筛查失败 | 0% | 人工复核并淘汰 |
| 软约束 | 强 5′端二级结构 | <5% | 降权或重新设计 |
| 软约束 | 局部 GC 极端 | <5% | 降权 |
| 软约束 | 稀有密码子聚集 | <5% | 降权 |
| 软约束 | 重复序列 | <5% | 降权 |
| 软约束 | 剪接样信号 | <5% | 降权 |

**约束违反率计算公式**：

\[
\text{Hard Violation Rate} = \frac{\text{违反至少一个硬约束的候选数}}{\text{总候选数}} \times 100\%
\]

\[
\text{Per-candidate Violation Count} = \frac{\text{总违反项数}}{\text{总候选数}}
\]

# 四、评估协议

1. **数据划分**
   - 按基因/蛋白划分，避免同一蛋白的同义变体泄漏。
   - 按实验批次划分，测试跨批次泛化。
   - 按细胞类型划分，测试跨细胞类型泛化。
   - 按物种划分，测试跨物种泛化。

2. **标签归一化**
   - within-assay z-score；
   - 相对阳性对照；
   - rank / percentile；
   - batch correction。

3. **统计指标**
   - 回归：Spearman、Pearson、R²、MAE；
   - 分类：AUC、AUPRC、F1；
   - 排序：NDCG、Top-k recall、pairwise accuracy；
   - 生成：氨基酸保持率、GC 分布、MFE、motif 违反率。

4. **实验验证**
   - 每批包含阳性对照、阴性对照、基线对照；
   - 记录细胞类型、修饰、递送、剂量、时间点；
   - 至少 3 个生物学重复；
   - 数据回传后更新模型。

# 五、结论

本指标字典覆盖了表达、半衰期、TE、免疫、可制造性和约束违反率六大类。核心验收原则是：

1. **蛋白正确性 100%**；
2. **硬约束违反率 0%，安全筛查 100% 通过**；
3. **预测指标显著优于基线**；
4. **实验 top-10 候选中有足够比例优于对照**；
5. **可制造性满足 IVT 和生产要求**；
6. **全流程可追溯、可审计、可人工审核**。

这些指标可直接用于 PRD v0 的验收标准、模型评估和后续实验闭环。
