# 需求工作坊产出：PRD v0 + 系统边界

## 0. 工作坊基本信息

- **产品代号**：Eir 北欧神话中的医疗女神 Eir（埃伊尔）。她是医疗、治愈与仁慈的化身，常与草药、康复和生命力的恢复联系在一起。
- **目标**：开发一个 AI 模型，针对患者提供的基因样本，生成有效、稳定、低免疫原性、可制造且安全的 mRNA 序列。
- **核心用户**：临床医生、分子生物学家、生物信息学家、mRNA 工艺开发人员、监管/伦理审查人员。
- **核心输出**：患者特异性 mRNA 候选序列、评分报告、安全筛查报告、实验建议。
- **工作坊目标**：明确设计目标、应用场景、成功指标，形成 PRD v0 和系统边界。

---

# 一、产品愿景

构建一个“从患者基因样本到 mRNA 候选序列”的 AI 设计平台：

```text
患者基因样本
→ 测序与变异分析（上游）
→ 确定目标蛋白/抗原序列
→ AI 生成 mRNA 候选
→ 多任务评分与约束优化
→ 安全筛查
→ 输出 top-N 可合成、可实验验证的 mRNA 序列
```

AI 模型的核心任务不是诊断疾病，也不是决定治疗方案，而是：

> 在给定目标蛋白序列、患者细胞/组织背景、递送方式和修饰核苷酸条件下，设计出能正确翻译、稳定、高表达、低免疫刺激、易生产的 mRNA 序列。

# 二、设计目标

## 2.1 一级目标

1. **编码正确蛋白质**
   - ORF 必须翻译成目标氨基酸序列。
   - 同义密码子可变，但蛋白序列 100% 不变。
   - 无内部意外终止密码子、无移码。

2. **提高翻译效率**
   - 优化密码子使用偏好。
   - 优化 5′UTR、Kozak 区域、起始密码子附近结构。
   - 避免 5′端过强二级结构。

3. **提高 mRNA 稳定性**
   - 控制 GC 含量，建议 40%–60%。
   - 优化 5′UTR、3′UTR、poly(A) 特征。
   - 降低不利二级结构和降解热点。

4. **降低免疫刺激**
   - 避免免疫刺激性 motif。
   - 控制 dsRNA 倾向。
   - 支持 m1Ψ 等修饰核苷酸条件设计。

5. **提升可制造性**
   - 避免长同聚物、重复序列、极端 GC 区。
   - 避免限制性酶切位点、剪接样信号、早停信号。
   - 提高 IVT 产率和全长比例。

6. **满足安全与合规**
   - 内置生物安全筛查。
   - 过滤受控病原体、毒素、危险序列。
   - 保护患者遗传数据隐私。
   - 所有候选必须经过人工审核。

## 2.2 二级目标

- 支持患者细胞类型特异性设计。
- 支持不同递送系统（LNP、电穿孔等）。
- 支持不同应用场景（蛋白替代、肿瘤新抗原、罕见病）。
- 支持多目标 Pareto 优化。
- 支持实验数据闭环迭代。

# 三、应用场景

## 场景 A：罕见遗传病蛋白替代

- 患者基因样本测序发现致病突变。
- 确定需要补充的正常蛋白序列。
- AI 设计 mRNA，使患者在体内表达正常蛋白。
- 重点：高表达、长半衰期、低免疫刺激。

## 场景 B：个性化肿瘤新抗原疫苗

- 患者肿瘤样本测序，识别新抗原。
- 确定新抗原串联体或单抗原序列。
- AI 设计 mRNA 疫苗序列。
- 重点：表达、稳定性、适度免疫激活、安全性。

## 场景 C：患者特异性治疗性蛋白

- 患者需要某种治疗性蛋白，如酶、抗体、细胞因子。
- 给定目标蛋白序列和患者背景。
- AI 生成优化 mRNA 候选。
- 重点：可制造性、低免疫原性、组织特异性表达。

## 场景 D：体外验证与科研

- 科研人员给定蛋白序列，快速生成候选 mRNA。
- 用于细胞实验、动物实验。
- 重点：快速周转、多候选、可实验验证。

# 四、用户故事

1. 作为临床医生，我希望上传患者目标蛋白序列和细胞类型，获得 top-10 mRNA 候选，以便与分子生物学家讨论治疗方案。
2. 作为生物信息学家，我希望系统自动检查 ORF、GC、二级结构和安全风险，减少人工筛查。
3. 作为 mRNA 工艺人员，我希望候选序列避免长同聚物和极端 GC，以提高 IVT 产率。
4. 作为安全审查员，我希望所有候选都经过生物安全筛查，并保留审查记录。
5. 作为研究者，我希望系统输出候选评分、不确定性和实验建议，方便设计湿实验。
6. 作为监管/伦理人员，我希望患者数据脱敏、访问受控、全流程可追溯。

# 八、系统边界

## 8.1 系统包含

1. **输入接口**
   - 目标蛋白氨基酸序列
   - 患者/细胞类型/物种/修饰核苷酸/递送方式
   - 优化目标权重和约束

2. **AI 设计核心**
   - 条件 Transformer 生成同义 CDS
   - 5′UTR、3′UTR、poly(A) 设计/选择
   - RNA 结构感知模块
   - 多任务预测器
   - 约束解码与多目标优化

3. **安全与合规**
   - 生物安全筛查
   - 患者隐私保护
   - 审计日志
   - 人工审核门

4. **输出**
   - top-N mRNA 候选序列
   - 评分、不确定性、约束报告
   - 安全筛查报告
   - 实验建议

5. **闭环**
   - 实验数据回传
   - 模型更新
   - 版本追踪

## 8.2 系统不包含

1. **临床诊断**
   - 不进行疾病诊断、变异致病性判定。
   - 不替代医生决策。

2. **原始测序数据处理**
   - 不做原始 FASTQ 质控、比对、变异 calling。
   - 这些由上游临床/生信流程完成。

3. **目标蛋白选择**
   - 不决定用哪个蛋白、哪个抗原、哪个适应症。
   - 由医生和科学家决定。

4. **递送系统开发**
   - 不设计 LNP 配方、不优化递送载体。

5. **GMP 生产**
   - 不执行合成、IVT、纯化、灌装。
   - 不负责临床级生产。

6. **临床与监管**
   - 不做临床试验、不提交监管申报。
   - 不提供临床治疗方案。

7. **自动化合成**
   - 不直接连接合成仪或灌装线。
   - 仅输出序列和报告。

# 十、风险、合规与假设

## 风险

- 患者数据隐私与伦理风险。
- 公开数据不足，免疫和可制造性标签稀缺。
- 模型预测与真实实验存在差距。
- 生物安全风险，可能生成受控序列。
- 临床转化和监管路径复杂。

## 合规要求

- 伦理审查 IRB。
- 患者知情同意。
- 数据脱敏与加密。
- 生物安全筛查。
- 人工审核。
- 全流程审计。

## 假设

- 上游已提供可信的目标蛋白序列。
- 临床医生和分子生物学家参与审核。
- 实验验证可回传数据。
- 生产由外部 GMP 设施完成。

# 十一、MVP 范围与验收标准

## MVP 范围

- 输入目标蛋白序列和基本条件。
- 生成同义 CDS + 5′UTR/3′UTR/polyA 候选。
- 多任务预测表达、稳定性、免疫风险。
- 约束解码和安全筛查。
- 输出 top-10 候选报告。

## 验收标准

1. 100% 候选翻译后与目标蛋白一致。
2. GC 40%–60%，无内部 stop，同聚物≤4。
3. 所有候选通过安全筛查。
4. 单患者候选生成 <1 小时。
5. top-10 候选可合成率 >90%。
6. 报告包含评分、不确定性、约束和审核状态。

## PRD v0 结论

**Patient-mRNA Designer** 是一个面向患者特异性 mRNA 治疗的 AI 设计系统。它从目标蛋白序列出发，生成正确、稳定、高表达、低免疫、可制造且安全的 mRNA 候选。系统边界明确：**只做 mRNA 序列设计与评估，不做诊断、不做目标选择、不做递送、不做 GMP 生产、不做临床决策。** 所有候选必须经过安全筛查和人工审核。
