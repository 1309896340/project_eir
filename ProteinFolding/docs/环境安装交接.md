# ProteinFolding · 环境安装交接清单

> 按约定,以下大体积 / 需外网的安装由你亲自执行。每一步都给出确切命令、
> 预期产物与验证方法。逐项执行后告诉我结果即可;哪一步卡住就停在哪一步。

## ① 切换 GPU 版 torch(约 2.5 GB,上海交大镜像)

当前环境是 CPU 版 torch(2.x+cpu)。ProteinFolding 的本地 ESM3 推理需要 GPU
版本;CodonTransformer 的 CPU 推理不受影响(GPU 轮子同样含 CPU 后端)。

pyproject.toml 已按 AGENTS.md 预留的路径配置好 `[[tool.uv.index]]` explicit
源(sjtu pytorch-wheels/cu126)。执行:

```bash
uv sync
```

- 预期:下载 torch+cu126 相关轮子(约 2.5 GB),完成后 `uv run python -c "import torch; print(torch.__version__, torch.cuda.is_available())"` 应输出 `2.x.x+cu126 True`。
- 注意:nvidia-smi 显示驱动兼容 CUDA 13.1,cu126 运行时在其兼容范围内。
- 若 sjtu 镜像缺 cu126 的新版轮子,备选 `cu128`/`cu130` 源(改 pyproject 中 index URL 即可),驱动同样兼容。

## ② 安装 openmm[cuda13](约 1 GB,PyPI/阿里云)

OpenMM 的 CUDA 平台在 extras 里(轮子捆绑 CUDA 运行时,只需驱动、无需装
CUDA Toolkit)。执行:

```bash
uv add "openmm[cuda13]"
```

- 预期:安装 OpenMM-CUDA-13==8.x。验证:

```bash
uv run python -c "import openmm; print([openmm.Platform.getPlatform(i).getName() for i in range(openmm.Platform.getNumPlatforms())])"
```

  应看到列表里多了 `CUDA`。
- 此后 ProteinFolding 界面的「计算平台」选"自动检测"即会优先走 CUDA。

## ③ 下载 ESM3 开放权重(约 3.4 GB,hf-mirror,无需账号)

esm3-sm-open-v1 已迁移到 HF 的 `biohub` 组织,**未 gated,匿名可下**。
目标目录:`ProteinFolding/data/esm3/`(目录结构需与仓库一致)。

在仓库根目录执行(PowerShell 或 Git Bash 均可):

```bash
# 用 huggingface_hub 指向 hf-mirror 下载(已随 esm 包装好)
uv run python -c "
import os
os.environ['HF_ENDPOINT'] = 'https://hf-mirror.com'
from huggingface_hub import snapshot_download
snapshot_download('biohub/esm3-sm-open-v1', local_dir='ProteinFolding/data/esm3')
"
```

- 若 `huggingface_hub` 在 hf-mirror 上报 308/HEAD 相关错误(本项目已知的
  hf-mirror 兼容问题),改用直接逐文件下载(同样在仓库根目录):

```bash
uv run python -c "
import urllib.request, os
base = 'https://hf-mirror.com/biohub/esm3-sm-open-v1/resolve/main/'
files = [
    'config.json',
    'data/weights/esm3_sm_open_v1.pth',
    'data/weights/esm3_structure_encoder_v0.pth',
    'data/weights/esm3_structure_decoder_v0.pth',
    'data/weights/esm3_function_decoder_v0.pth',
]
for f in files:
    dest = os.path.join('ProteinFolding', 'data', 'esm3', *f.split('/'))
    os.makedirs(os.path.dirname(dest), exist_ok=True)
    print('downloading', f)
    urllib.request.urlretrieve(base + f, dest)
print('done')
"
```

  (主权重 esm3_sm_open_v1.pth 约 2.6 GB;若嫌 Python 下载慢,也可以用浏览器
  直接访问 `https://hf-mirror.com/biohub/esm3-sm-open-v1/tree/main` 手动下载
  上述 5 个文件并按相同相对路径放置。)

- 验证:

```bash
uv run python -m ProteinFolding.demo --sample ins --preset fast --force
```

  能看到「结构预测(esm3-local)」并一路跑完即成功。首次加载权重需约
  10~30 秒;CPU 推理较慢,GPU 就绪后为秒级。

## 完成后

三项都完成后,`ProteinFolding` 即为完整能力:本地 ESM3 秒级结构预测 +
OpenMM CUDA 加速。运行 `uv run python -m ProteinFolding.app` 即可使用。
