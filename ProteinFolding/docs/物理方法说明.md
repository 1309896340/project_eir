# ProteinFolding · 物理方法说明

本文档说明折叠动画的生成原理、参数含义与科学口径。界面文案中的"物理引导
示意"即源于此。

## 总览

管线分四步:

```text
氨基酸序列
  → 结构预测(ESM3 本地权重 / Forge API) → native.pdb(天然态)
  → 全延伸线性链重建(NeRF 内坐标 + Kabsch 叠合) → linear.pdb(起点)
  → 折叠动画(内坐标关键帧形变 + 最小间距松弛 + 终点 GBn2 物理松弛)
    → trajectory.dcd(动画轨迹)
  → 浏览器 Mol* 播放
```

## 1 · 起点与终点

- **终点(native.pdb)**:结构预测器的输出。默认本地 ESM3(esm3-sm-open-v1,
  与 HF 仓库 biohub/esm3-sm-open-v1 相同权重);权重未就绪或需回退时走
  Forge API(需 FORGE_API_KEY)。也支持直接给定 PDB(跳过预测)。
- **起点(linear.pdb)**:不是简单的"拉直"。主链按理想内坐标重建为全延伸
  (β 折叠式)构象:φ=-139°、ψ=+135°、ω=180°;每个残基的 O 按理想肽平面
  放置(sp2 平面、绕 C-N 肽键轴与 CA 反式),CB 与侧链原子通过 Kabsch
  叠合(N,CA,C 三点局部参考系)从天然构象搬运,保留侧链内角与手性;
  C 端缺 OXT 时按标准羧基几何补齐(amber14 模板必需)。

## 2 · 折叠动画的生成(核心)

动画主体是**内坐标关键帧形变**(internal-coordinate morphing),终点由
**真实分子动力学松弛**收尾:

1. **关键帧路径**:提取天然态每个残基的 (φ, ψ, ω);形变进度 s∈[0,1] 时,
   二面角逐残基从全延伸值插值到天然值(角度走最短弧),用 NeRF 内坐标
   实时重建主链坐标,O 按理想肽平面放置,侧链按局部参考系 Kabsch 叠合。
   **任意中间态都是键长键角理想的可行构象**——原子跟随的是一条真实
   可折叠的路径(与 PyMOL/Chimera 的 morph 同源思想)。
2. **最小间距松弛**:形变中段链段互相穿越不可避免,穿越时会出现非键合
   近重合原子对。每个关键帧生成后做纯几何的最小间距松弛:把距离小于
   2.4 Å 的非键合原子对(排除 1-2/1-3 键合近邻)沿连线分摊推开,单原子
   每迭代位移封顶 0.05 Å。这保证任何帧里都没有会使力场发散的近重合。
3. **终点松弛(真实物理)**:形变完成后切换到完整 AMBER14SB + GBn2
   隐式溶剂系统,先能量最小化,再做朗之万恒温自由 MD(标准档 1500 步
   ≈ 3 ps)。动画最后一段是真实的物理收敛过程。

### 为什么不是经典 targeted MD?

开发过程中系统实测过经典 TMD(固定天然态目标 + 力常数爬升的简谐外力)
及其多个变体(笛卡尔直线插值目标、自适应步调门控、软核缩放 2%~零、
高摩擦),结论:

- **笛卡尔插值路径不可行**:全延伸"直棒链"反向折叠时,链段必须互相
  穿越;线性插值的目标会让键合几何与目标位置冲突,谐振拉力把体系顶爆
  (vdW r^-12 与 GB Born 项在近重合时发散,IEEE 0×∞=NaN 使"零电荷"
  也无效);
- **力驱动的传输速度存在物理上限**:谐振力 + 分子摩擦下的漂移速度
  (实测 ~0.6 Å/ps @ F=1500 kJ/mol/nm、γ=5/ps)远低于把 150 Å 旅程
  塞进演示可接受时长的需求,拉大力常数则直接触发约束求解失败;
- **CPU 平台的 Langevin 随机速度 + 约束投影 + 高频 setPositions 组合
  存在偶发数值发散**(实测),Verlet + 零速度稳定。

因此最终架构为:**形变交给几何(内坐标 morph,逐帧保证键合几何、
无积分、无爆散通道),物理交给松弛(完整 GBn2 最小化 + 朗之万 MD)**。
这与 PyMOL/Chimera 等成熟工具的 morph 实现思路一致,是演示动画的
业界常规做法。

### 双系统设计

- **morph 系统**:不含 GB、非键电荷与 epsilon 全零——形变阶段只有
  键合力场(实际未积分,仅为完整性保留);
- **relax 系统**:完整 AMBER14SB + GBn2,用于终点松弛。
- 形变完成后把坐标传入 relax 系统:最小化(吸收 H 偏移等几何近似)→
  朗之万自由 MD。松弛阶段若偶发 NaN,自动降档重试(最多 2 次)。

## 3 · 参数含义(高级面板)

| 参数 | 默认(标准档) | 含义 |
|---|---|---|
| guide_steps | 3500 | 预留(形变阶段为几何关键帧,步数由帧数与残基数决定) |
| relax_steps | 1500 | 终点松弛 MD 步数(按残基数自动放大:max(值, 残基数×20)) |
| n_frames | 250 | DCD 轨迹总帧数 |
| k_max | 5000 | 预留(现行架构无引导外力) |
| temperature_K | 300 | 朗之万恒温器温度(松弛阶段) |
| timestep_fs | 2 | 积分步长(松弛阶段) |
| friction_per_ps | 2 | 朗之万摩擦系数 |
| minimization_iters | 500 | 最小化迭代数(起点与松弛切换时各一次) |
| seed | 42 | 随机种子(None = 每次随机) |

三档预设:快速预览(2000+800)/标准(3500+1500)/高质量(5000+2500),
主要差异在松弛步数与帧数。

## 4 · 科学口径(重要)

这段动画是**物理约束下的构象插值示意 + 真实力场松弛**,不是真实折叠路径:

- 中间构象保证键长键角理想、无原子近重合、无爆散,但**不代表真实折叠
  事件**(成核、中间态、路径分支)——真实折叠发生在微秒~毫秒级,而演示
  动画的"时间"是几何插值坐标,无量纲;
- 插值路径沿二面角最短弧走,可能穿过真实折叠不会经过的构象;
- 终点松弛段(动画结尾)是真实的 AMBER14SB+GBn2 动力学,其结构能量上
  合理,但不等于天然态自由能极小;
- 适用:教学演示、结构对比、pipeline 可视化。不适用:折叠机制研究、
  定量动力学分析。

## 5 · 已知边界

- 序列限 20~400 aa、标准 20 残基(非标准残基会被力场拒绝);
- 结构预测质量决定动画终点质量:低置信度预测(如长无序区)折叠终点
  RMSD 偏大属正常;
- 终点 RMSD 典型值:20aa ~4 Å,76aa ~3.6 Å(相对预测结构的重原子 RMSD,
  含形态对齐偏差);该值衡量"动画贴合度",不是结构预测精度;
- 形变中段链段穿越时,弛豫把近重合原子对推开会产生轻微的"抖动",
  属预期行为。
