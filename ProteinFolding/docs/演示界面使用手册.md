# ProteinFolding · 演示界面使用手册

## 启动

```bash
uv run python -m ProteinFolding.app
```

服务就绪后自动打开浏览器(地址 `http://127.0.0.1:7861`)。VS Code 里也可
直接 F5(launch.json 已配置)。命令行不开浏览器的端到端入口见文末 demo。

## 界面三步

### 1 · 输入氨基酸序列

- 直接粘贴(支持 FASTA 文本,自动取首条);
- 或点「上传 FASTA」;
- 或点内置样例:INS 胰岛素原 110aa / HBB 血红蛋白β 147aa / EPO 193aa
  (GENCODE v50 真实人类蛋白,与 CodonTransformer 演示界面共用)。

长度支持 20~400 aa,仅限标准 20 种残基。超过 300 aa 会提示模拟耗时增加。

### 2 · 模拟设置

- **预设档位**:快速预览(最快出结果)/ 标准 / 高质量(更平滑的轨迹);
- **高级参数 / 平台**(可折叠):步数、帧数、力常数、温度、随机种子等
  逐项覆盖(留空用档位默认);计算平台选"自动检测"(有 CUDA 时自动用)
  或强制 CPU/CUDA/OpenCL;
- **强制重算**:忽略同名缓存,重新模拟一遍。

点「生成折叠动画」后进度条依次显示:结构预测 → 线性链构建 → 能量最小化
→ 引导折叠(带逐帧 RMSD)→ 终点松弛。

### 3 · 结果

- **Mol* 查看器**:自动加载拓扑与轨迹,默认卡通模型;
- **播放控制**:播放/暂停、进度拖拽、速度(4~30 帧/秒)、显示样式
  (卡通/球棍/空间填充);
- **导出视频**:点「● 导出视频」后自动从头录制一遍并下载 webm
  (分辨率与浏览器窗口一致;再次点击可提前停止);
- **下载产物**:native.pdb / linear.pdb / trajectory.dcd / meta.json;
- **RMSD 曲线**:相对天然态的重原子 RMSD 随帧收敛情况。

## 缓存

相同 序列+参数(+管线版本)的结果自动缓存于
`ProteinFolding/data/cache/<hash>/`,重复提交瞬时返回;改任何高级参数、
档位或勾选"强制重算"都会重新计算。缓存可直接删除,不影响功能。

## 命令行(demo)

```bash
uv run python -m ProteinFolding.demo --sample ins --preset standard
uv run python -m ProteinFolding.demo --native-pdb some_structure.pdb  # 折叠已知 PDB
uv run python -m ProteinFolding.demo --sequence-file protein.fa --preset fast --platform CUDA
```

产物写在 `ProteinFolding/data/cache/<hash>/`(或 `--out` 指定目录)。

## 常见问题

- **首次运行卡在"结构预测"**:本地 ESM3 权重未下载(见
  `docs/环境安装交接.md`);未配置权重与 FORGE_API_KEY 时界面顶部
  "预测器"会显示未就绪。
- **大序列慢**:110aa 标准 CPU 约 1~2 分钟,193aa 约 5~10 分钟;
  CUDA 就绪后快一个量级。可以先跑"快速预览"档。
- **动画末端与 native.pdb 不完全重合**:预期行为,终点松弛只保证能量
  合理(见 物理方法说明.md 的科学口径)。
- **端口冲突**:7861 被占用时,改 `app.py` 中 `main()` 的端口常量。
