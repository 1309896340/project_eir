# CodonTransformer 演示界面使用手册

> 更新日期:2026-09-24。适用对象:`CodonTransformer/codontransformer_app.py`(gradio 调试界面)。
> 功能:输入蛋白序列,选择宿主生物,一键生成宿主特异的密码子优化 CDS(DNA/mRNA 编码区),并支持批量采样同义变体。

---

## 一、简介

本界面是 [CodonTransformer](https://github.com/adibvafa/CodonTransformer)(Nature 2025,BigBird 架构,164 物种、100 万+ DNA-蛋白对训练)的本地推理调试台:

- **输入**:一段蛋白序列(单字母氨基酸)+ 宿主物种(如 Homo sapiens);
- **输出**:该宿主下密码子使用偏好优化的 CDS 序列(DNA 与 RNA 两个版本),附 GC 含量、翻译一致性校验;
- **采样模式**:一次生成多条"同义但密码子选择不同"的变体,用于展示同义序列设计空间。

权重从本地 `CodonTransformer/data/` 加载(约 358MB),**运行不需要联网**。CPU 推理单条序列约 1–3 秒。

## 二、环境准备(首次使用)

1. 已安装 [uv](https://docs.astral.sh/uv/),并在项目根目录执行过依赖安装:

   ```bash
   uv sync
   ```

2. 确认权重文件齐全(`CodonTransformer/data/` 下应有 `model.safetensors` 358MB 及 config/tokenizer 共 6 个文件)。

3. Python 版本固定为 3.12(项目 `pyproject.toml` 已锁定,`uv sync` 会自动准备)。

满足以上两条即可,无需额外配置。

## 三、启动方式

**方式 A:VS Code 一键调试(推荐)**

用 `RNADesign.code-workspace` 打开项目 → 按 `F5` → 选择启动项 **"CodonTransformer 调试界面 (gradio :7860)"**。服务就绪后会自动在浏览器打开页面。

**方式 B:命令行**

```bash
uv run python CodonTransformer/codontransformer_app.py
```

浏览器访问 **http://127.0.0.1:7860**(启动时会自动打开)。

首次启动需加载模型,约十几秒;看到 "Running on local URL" 即就绪。停止:在终端按 `Ctrl+C`,或结束对应 Python 进程。

## 四、界面布局

```
┌─────────── 左列:输入 ───────────┐  ┌─────────── 右列:输出 ───────────┐
│ 蛋白序列(多行文本框)            │  │ 概览(宿主/长度/GC/一致性/耗时)   │
│ 宿主(下拉,可输入过滤,164 物种) │  │ 优化 DNA(5'→3',T)              │
│ 解码模式(确定性 / 采样)         │  │ RNA 版本(T→U)                  │
│ match_protein 勾选框            │  │ 翻译产物(应为原蛋白)            │
│ ▸ 采样参数(折叠区)             │  │ 同义变体表(仅采样模式)          │
│ [生成优化 CDS] 按钮             │  │                                 │
│ 测试样例(3 个,点击即填入)      │  │                                 │
└────────────────────────────────┘  └─────────────────────────────────┘
```

## 五、操作步骤(标准流程)

1. **填入蛋白序列**:单字母氨基酸(如 `MALWMRLL…`),或直接点击底部测试样例之一;
2. **选择宿主**:下拉选择(输入关键字过滤),默认 `Homo sapiens`;
3. **选择解码模式**:单条最优设计选"确定性";想看多条候选选"采样";
4. **点击【生成优化 CDS】**;
5. **查看右侧结果**:先看概览行的"翻译一致"是否 ✅,再取 DNA/RNA 序列使用。

## 六、参数说明

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| 宿主 organism | 164 物种 | Homo sapiens | 决定模型条件生成的密码子偏好;如 `Escherichia coli general`(大肠杆菌) |
| 解码模式 | 确定性 / 采样 | 确定性 | 确定性=每位置取模型最优密码子,结果唯一;采样=按概率抽样,可出多条 |
| match_protein | 开/关 | 开 | **同义约束**:只允许选择编码原氨基酸的密码子(实现为非同义密码子 logits 置 -inf)。演示与生产场景均建议保持开启 |
| temperature | 0.1–0.9 | 0.5 | 仅采样模式。越低越保守(0.2≈接近最优),越高越多样(0.8 可能偏离最优) |
| top_p | 0.5–1.0 | 0.95 | 仅采样模式。核采样阈值,截断累计概率之外的密码子 |
| num_sequences | 1–5 | 3 | 仅采样模式。生成变体条数 |

## 七、测试样例与推荐演示流程

三个样例均为 **GENCODE v50 真实人类蛋白**(序列提取自 `data/gencode/human/gencode.v50.pc_translations.fa.gz`),点击样例卡即自动填入全部参数:

| 样例 | 蛋白 | 长度 | 预置配置 | 演示点 |
|---|---|---|---|---|
| 1 | INS 胰岛素原 (ENSP00000380432) | 110 aa | Homo sapiens · 确定性 | 最优单条设计;翻译一致 ✅;GC 约 58% |
| 2 | HBB 血红蛋白β (ENSP00000333994) | 147 aa | Homo sapiens · 采样 | 多条同义变体的 GC 差异(同义≠唯一) |
| 3 | EPO 促红细胞生成素 (ENSP00000802629) | 193 aa | **大肠杆菌** · 采样 | 同一蛋白换宿主,密码子选择整体改变(条件生成的意义) |

**建议演示顺序(约 3 分钟)**:

1. 点样例 1 → 生成:展示"蛋白进、CDS 出"的最短闭环,强调翻译一致 ✅ 与 RNA 版本;
2. 点样例 2 → 生成:对比变体表中各条的 GC 与序列差异,说明设计空间;
3. 点样例 3 → 生成:先切回 Homo sapiens 生成一次,再用样例预置的大肠杆菌生成一次,对比两条 DNA,直观展示"宿主条件"如何改变输出;
4. (可选)把 match_protein 关掉再生成:演示无约束时模型可能产生不翻译回原蛋白的序列——说明硬约束的必要性,演示后记得重新勾上。

## 八、结果解读

- **概览**:`翻译一致 ✅` 表示生成 CDS 按标准密码子表翻译后与输入蛋白完全一致(硬约束校验通过);❌ 说明序列有问题(见 FAQ);`GC` 正常范围约 40%–60%,人类 CDS 多在 45%–60%。
- **优化 DNA**:5'→3' 方向、以 T 表示胸腺嘧啶(DNA 写法),长度 = 氨基酸数 × 3,以 ATG(起始)开头、以终止密码子(TAA/TAG/TGA)结尾。
- **RNA 版本**:同一序列的 RNA 写法(T→U),即最终 mRNA 的 CDS 部分,符合本项目"序列统一用 RNA 表示"的约定。
- **翻译产物**:回译校验结果,应与输入蛋白一致(可能带尾部终止符 `_`)。
- **同义变体表**:每条变体翻译产物相同,但密码子选择不同、GC 不同——这正是密码子优化要搜索的空间;可能出现重复条目(采样随机性,正常)。

## 九、常见问题(FAQ)

| 现象 | 原因与处理 |
|---|---|
| 启动报 `OSError: We couldn't connect to huggingface.co` | 权重不在本地。确认 `CodonTransformer/data/model.safetensors` 存在;界面只会从该目录加载,不联网下载 |
| 提示端口被占用 / `Cannot start server on 7860` | 已有实例在跑(可能上次没关)。结束旧 Python 进程,或改脚本末尾 `server_port` |
| 翻译一致显示 ❌ | 多为关闭了 match_protein 且 temperature 调太高(如 0.8)。重新勾选 match_protein 或调低 temperature |
| F5 无反应 / 找不到解释器 | 用 `RNADesign.code-workspace` 打开项目;或检查 `.venv\Scripts\python.exe` 是否存在(不存在则先 `uv sync`) |
| 变体出现重复序列 | 采样随机性所致,属正常;可调低 temperature 减少重复 |
| 蛋白序列校验报错 | 检查是否混入数字/空格/非法字符;输入会自动去空白并转大写,但必须是标准 20 种单字母氨基酸 |
| 推理偏慢 | 默认 CPU 推理,单条 1–3 秒、193aa 约数秒,属正常;如需提速可另配 GPU 版 torch(见 pyproject.toml 注释) |

## 十、注意事项与边界

1. 本界面输出的是 **CDS 编码区**,不含 5'UTR / 3'UTR / poly(A);完整 mRNA 设计是本项目的后续目标。
2. 模型输出为概率最优的"天然偏好"序列,**不等于**表达/稳定性/免疫原性最优;多目标打分与约束解码由本项目后续模块承担。
3. 涉及真实设计与合成时,必须遵守项目安全约定(序列安全筛查模块),不得省略。
4. 该目录(`CodonTransformer/`)为 .gitignore 忽略的本地模型工作区,本手册与应用文件均不入 git;项目级文档请放 `docs/` 或 `reference/`。
